# KỸ NĂNG & TIÊU CHUẨN FRONTEND VIONE (FE PWA)

## 1. Công nghệ cốt lõi
- Vite + React 18 + TypeScript.
- TanStack Router cho hệ thống định tuyến type-safe (`connect-app.inbox.*`, `connect-app.executive`, v.v.).
- TailwindCSS và CSS Modules tuân thủ bảng màu ViOne.
- Web Speech API (`webkitSpeechRecognition` / `SpeechRecognition`) cho trợ lý giọng nói AI.
- Lucide React cho hệ thống icon thanh lịch, tinh giản.

## 2. Kỹ năng vận hành UI/UX & Doanh nghiệp
- Quản lý trạng thái Realtime qua Socket.io client.
- Xử lý tiến độ công việc và import dữ liệu Excel trên trình duyệt.
- Tối ưu hóa PWA: Service Worker, Responsive theo chuẩn Mobile App PWA và Desktop Web.
